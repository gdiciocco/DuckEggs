# DuckEggs v0.4.0-alpha.2

This alpha improves the DuckEggs window and its donation flow.

[Download DuckEggs 0.4.0-alpha.2 for Windows](https://github.com/gdiciocco/DuckEggs/releases/download/v0.4.0-alpha.2/DuckEggs-0.4.0-alpha.2-windows-x64.zip)

See the
[v0.4.0-alpha.2 pre-release](https://github.com/gdiciocco/DuckEggs/releases/tag/v0.4.0-alpha.2)
for release details.

## What's new

- The product quote is more compact, and UI updates cause less flicker.
- **To tray** hides the window while preserving its current paused or running
  state. The notification-area icon restores DuckEggs and offers Open,
  Pause/Resume and Exit. Closing the window still exits.
- The more prominent gold **Donate** action opens a donation chooser with
  voluntary suggested amounts of €2, €5 and €10, plus a custom amount through
  PayPal.

## Early alpha

DuckEggs requires Windows 10 or Windows 11, 64-bit, and Google Chrome. It starts
paused, supports one Chrome picture-in-picture window at a time, and is
unsigned. As an early alpha, it may have rough edges and bugs.

Learning data stays on your PC in `%LOCALAPPDATA%\DuckEggs`. DuckEggs does not
store screenshots or include analytics.

If something does not work as expected,
[open a GitHub issue](https://github.com/gdiciocco/DuckEggs/issues).
