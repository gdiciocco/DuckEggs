# DuckEggs v0.4.0-alpha.3

This alpha fixes Chrome picture-in-picture recognition when Chrome is using a
non-English language.

[Download DuckEggs 0.4.0-alpha.3 for Windows](https://github.com/gdiciocco/DuckEggs/releases/download/v0.4.0-alpha.3/DuckEggs-0.4.0-alpha.3-windows-x64.zip)

## What's new

- Non-English Chrome picture-in-picture windows were previously not recognized;
  DuckEggs now matches official localized Chrome PiP titles.

## Early alpha

DuckEggs requires Windows 10 or Windows 11, 64-bit, and Google Chrome. The
interface remains in English, and DuckEggs supports one Chrome
picture-in-picture window at a time. This build is unsigned and may have rough
edges and bugs.

Learning data stays on your PC in `%LOCALAPPDATA%\DuckEggs`. DuckEggs does not
store screenshots or include analytics.

If something does not work as expected,
[open a GitHub issue](https://github.com/gdiciocco/DuckEggs/issues).
